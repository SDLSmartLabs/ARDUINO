# 🌈 Mood Lamp with Sound Sensor

A NeoPixel lamp that changes color and intensity based on surrounding sound.

## 🎵 Features
- Reacts to sound or music  
- Creates colorful mood lighting  
- Smooth color transitions

## 🧩 Components
- Arduino Uno / Nano  
- Sound sensor (analog)  
- NeoPixel ring or strip  
- Jumper wires

## 🧠 How It Works
- Sound sensor reads amplitude  
- Colors dynamically change based on volume level
