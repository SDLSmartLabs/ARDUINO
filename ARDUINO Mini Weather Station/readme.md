# 🌤️ Mini Weather Station

Displays real-time temperature and humidity on a 16x2 LCD display using a DHT11 sensor.

## 🧠 Features
- Shows live temperature and humidity  
- Compact, simple circuit  
- Great beginner IoT project

## 🔧 Components
- Arduino Uno  
- DHT11 Sensor  
- 16x2 LCD display  
- Jumper wires and breadboard

## 🧩 How It Works
- Reads DHT11 data every 2 seconds  
- Displays temperature and humidity values on the LCD
