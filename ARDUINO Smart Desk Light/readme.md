# 💡 Smart Desk Light System

An automatic desk lighting system that adjusts brightness based on ambient light using an LDR sensor and NeoPixels.

## ✨ Features
- Auto-adjusts LED brightness
- Energy-efficient desk lighting
- Uses NeoPixel for soft lighting effect

## 🧩 Components
- Arduino Uno / Nano  
- LDR (light sensor)  
- NeoPixel strip (8 LEDs)  
- Jumper wires

## 🧠 How It Works
- Reads the ambient light using LDR  
- Inverts the brightness mapping (darker → brighter)  
- Lights adjust automatically in real-time
