# 🚪 Smart Door Alert System

Alerts when a door is opened using a reed switch, buzzer, and LED indicator.

## ⚙️ Features
- Detects door open/close status  
- Triggers buzzer and LED alarm  
- Simple and effective home security project

## 🔧 Components
- Arduino Uno  
- Magnetic reed switch  
- Buzzer  
- LED + 220Ω resistor  
- Jumper wires

## 🧠 How It Works
- Reed switch changes state when door opens  
- Arduino triggers buzzer and LED instantly
