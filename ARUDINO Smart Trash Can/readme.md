# 🗑️ Smart Trash Can

A touchless trash can that automatically opens when you approach it using an ultrasonic sensor and servo motor.

## 🤖 Features
- Hands-free lid opening  
- Closes automatically after 2 seconds  
- Uses ultrasonic sensor for detection

## 🧩 Components
- Arduino Uno  
- HC-SR04 Ultrasonic Sensor  
- Servo motor  
- Jumper wires and power supply

## 🧠 How It Works
- Measures distance using ultrasonic sensor  
- If object <15cm, servo opens lid  
- Lid auto-closes after short delay
